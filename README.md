
# ⏱️ Temporizador Pomodoro 🍅

<img align="right" width=200px alt="Abeja volando" src="https://raw.githubusercontent.com/MurielSoiffer/temporizadorPomodoro/master/img/tomato.gif"/>

Temporizador Pomodoro es una aplicación sencilla que utiliza la técnica de **Pomodoro** para mejorar la productividad, ayudando a los usuarios a trabajar en bloques de 25 minutos con pausas cortas entre ellos.

### 📦Requisitos

- 🟢 **Node.js**: Asegúrate de tener Node.js instalado. [Descargar Node.js](https://nodejs.org/)
- 💻 **Electron**: Este proyecto utiliza Electron para crear aplicaciones de escritorio.

## ✨ Funcionalidades

- ⏲️ **Temporizador Pomodoro**: Inicia un temporizador de 25 minutos para trabajar.
- ☕ **Pausa corta**: Después de 25 minutos, comienza automáticamente una pausa de 5 minutos.
- 🖥️ **Interfaz simple y amigable**: Diseño limpio y fácil de usar, perfecto para mantenerte enfocado.


## 🛠️ Instalación

### 1️⃣ Clonar el repositorio

Puedes clonar este proyecto en tu máquina utilizando el siguiente comando:

```bash
https://github.com/MurielSoiffer/temporizadorPomodoro.git
```

### 2️⃣ Instalar dependencias

Una vez que hayas clonado el repositorio, navega al directorio del proyecto y ejecuta el siguiente comando para instalar las dependencias:

```bash
cd temporizadorPomodoro
npm install
```

### 3️⃣ Ejecutar en desarrollo

Para ejecutar el proyecto en modo de desarrollo, usa el siguiente comando:

```bash
npm start
```
